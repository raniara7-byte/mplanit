포토샵 배너를 레이어 그대로 피그마로 — AIU본부 디자이너 가이드

ZIP 파일 다운로드v1.9.3 · 최신 배포판
2026.07 · 1차 내부 테스트

A설치 — 1분

  1. zip을 새 폴더에 압축 해제
  2. 캔버스 우클릭 → Plugins → Development → Import plugin from manifest…
  3. manifest.json 선택 — 끝
Widgets 메뉴 아님 · 업데이트는 기존 항목 제거 후 재등록 · 프레임 이름의 "v1.9.3"로 최신 확인

B사용 — 5단계

  1. PSD 드래그 — 내 PC 안에서만 처리
  2. Quality Score·이슈 확인
  3. 옵션은 파싱 전에 선택
  4. 보드 선택 → Figma로 가져오기
  5. 필요 시 레이어 이미지 ZIP 저장

C포토샵 체크 — 만들 때

  • 텍스트 래스터화 금지
  • 레이어 이름 정리
  • 이펙트 시안은 표시 상태로 저장 — 단, 한 번에 하나만 켜고 저장
  • 저장 시 호환성 최대화 켜기
  • Bevel·Satin·Pattern 최소화
  • 라이브 블러는 이름에 blur:20

D피그마 체크 — 쓸 때

  • 데스크톱 앱으로 사용
  • QA에 뜬 폰트를 PC에 설치
  • 세트 그룹 = 픽셀 원본이 시각 담당
  • 문구 수정 → 옵션 "숨김 편집용 텍스트 동봉" 켜고 변환
  • 색 차이 → "[대조] 포토샵 원본" 켜고 이미지 조정으로 보정

E변환 범위

  • 자동: 구조·텍스트·마스크 3종·클리핑 2종·이펙트 7종·칠 레이어·블렌드·불투명도·스마트오브젝트
  • Bevel·Satin·Pattern: 재현 불가 → [원본] 스냅샷 자동 동봉
  • 조정 레이어(Curves 등): 제외 → [대조] 켜고 30초 보정
  • 래스터 텍스트: 이미지로 유지

F피드백

  • 본인 PSD 1~2개 변환 → 다른 지점 캡처
  • 보낼 것: PSD + 결과 캡처 + 레이어 패널 캡처
  • 수신: AIU본부 랄라
