# MPLANIT Motion Studio — 영상 교체 가이드

## 가장 쉬운 교체 방법

1. 사이트 주소 뒤에 `/edit.html`을 붙여 영상 교체 화면을 엽니다.
2. 교체할 영역을 선택하고, 영상 파일(MP4/WebM) 또는 영상 주소를 입력합니다. 필요하면 포스터 이미지와 제목도 수정합니다.
3. **미리보기에 적용**으로 확인한 뒤 **완성 사이트 ZIP 다운로드**를 선택합니다.
4. ZIP을 개발 담당자에게 전달해 기존 사이트를 재배포합니다. 이 대화에 ZIP을 첨부해 업데이트를 요청할 수도 있습니다.

편집 화면은 변경 내용을 공개 사이트에 자동 저장하지 않습니다. 변경은 미리보기에서만 보이며, ZIP으로 내보내야 보관됩니다. 영상 파일까지 함께 보관하려면 설정 파일만 받는 대신 ZIP을 받으세요. 편집 도중 브라우저를 닫으면 내보내지 않은 변경은 사라집니다.

## 지원 형식

- 히어로 배경: MP4(H.264/AAC 권장), WebM. 자동재생은 무음이며, 방문자가 소리를 켤 수 있습니다.
- 개별 포트폴리오: MP4/WebM 직접 주소, YouTube 또는 Vimeo 공개/임베드 허용 링크.
- 이미지: JPG, PNG, WebP, GIF. SVG 업로드는 지원하지 않습니다.
- 영상 파일은 영역당 100MB 이하. 웹 재생에는 720p 또는 1080p, 5~20MB 권장.
- YouTube/Vimeo 영상의 공개 범위 및 임베드 허용 여부에 따라 재생이 제한될 수 있습니다.
- 외부 미디어 주소는 https를 권장합니다. 임시 서명 주소는 만료되므로 영구 주소를 사용하세요.

## 개발 담당자의 빠른 교체

`content.js`에 로고, 컬러, 히어로, 개별 작업물 데이터가 분리되어 있습니다. 레이아웃과 애니메이션을 바꿀 필요가 없습니다.

```js
hero: {
  id: 'hero',
  title: 'MPLANIT — Motion reel',
  video: 'assets/hero.mp4',
  poster: 'assets/hero-poster.jpg',
  mobilePosition: '50% 50%'
}
```

`works` 배열 각 항목의 `video`, `poster`, `title`, `description`을 바꿉니다. 실제 포트폴리오로 교체할 때 `concept: false`로 변경합니다. 갤러리 내 작업 순서는 배열 순서로 정합니다. `category`는 `BRAND FILM`, `LIVE ACTION & 3D`, `AI VISUAL` 중 하나로 사용합니다. `id`는 서로 다르게 유지합니다.

히어로는 모바일에서 영상의 가로 비율을 유지하며 배치합니다. 개별 영상은 팝업에서 원래 비율로 전체 재생됩니다. 움직임 줄이기 설정과 운영체제의 모션 감소 설정을 지원합니다.

## 현재 구성과 실제 연결 상태

- 첨부 영상 `KakaoTalk_20261001_003934011.mp4`: 히어로 및 첫 번째 영상 카드에 적용. 약 15.7초, 1280×720, 오디오 포함. 원본을 재인코딩하지 않았습니다.
- 원본 로고: 엠플랜잇 공식 사이트의 `/img/new-image/h1_logo.png`.
- 기획서: `영상홈페이지_구성안_한글카피_수정본 0923.pptx`의 카피, 섹션 흐름 및 제작 역량을 반영.
- 콘셉트 이미지 3종: 이 사이트 시안용으로 생성한 비주얼입니다. 실제 납품 실적으로 표기하지 않았으며 CONCEPT PREVIEW로 표시됩니다. 이미지 카드에는 동영상 재생을 가장하지 않고 이미지 미리보기를 제공합니다.
- 문의하기: 입력 내용을 사용자의 이메일 앱으로 넘기는 방식입니다. 사용자가 이메일 전송을 완료해야 문의가 접수됩니다. 자동 서버 접수, 데이터베이스 저장, 자동 회신은 연결되지 않았습니다.
- 별도 CMS/로그인/업로드 서버 없음. 편집 화면은 로컬 미리보기 및 파일 내보내기 도구이며, 관리자 인증 기능을 의미하지 않습니다.
- 새로운 브랜드 명칭은 `MPLANIT Motion Studio`를 시안용으로 적용했습니다.

## 회사 서버 배포

완성 ZIP 안의 `index.html`, `content.js`, `app.js`, `style.css`, `assets/`를 같은 폴더에 올리면 동작하는 정적 사이트입니다. 기존 회사 서버의 별도 서브도메인 또는 하위 경로에서 운영할 수 있습니다. `edit.html`, `editor.js`, `editor.css`, 본 가이드는 내부 작업 도구이므로 외부 공개 서버에는 필요할 때만 배포하세요.

브라우저에서 `index.html`을 바로 열어 기본 사이트를 볼 수 있습니다. 편집 화면의 전체 ZIP 내보내기는 파일 읽기 보안 제한으로 인해 웹서버에서 열었을 때 작동합니다. 로컬 서버 예: `python -m http.server 8080`.

글꼴은 Google Fonts와 Pretendard CDN을 사용하며 네트워크 제한 시 기본 글꼴로 표시됩니다.
