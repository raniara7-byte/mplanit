# MPLANIT Motion Studio

운영 사이트: https://mplanit-motion-studio.vercel.app/

## 배포

- GitHub 저장소: `raniara7-byte/mplanit`
- 운영 브랜치: `mplanit`
- Vercel 프로젝트: `mplanit-motion-studio`
- Vercel Root Directory: `motion-studio`
- Framework Preset: `Other`
- 별도 설치·빌드 명령 없이 정적 HTML, CSS, JavaScript와 `assets/`를 배포합니다.

이 폴더의 변경 사항을 `mplanit` 브랜치에 커밋하고 푸시하면 Vercel이 자동 배포합니다. ZIP 파일을 추가로 올릴 필요는 없습니다.

## 수정할 파일

- 화면 구성: `index.html`, `style.css`, `app.js`
- 콘텐츠: `content.js`, `content.json`
- 이미지·영상: `assets/`

`edit.html`은 로컬 콘텐츠 편집·내보내기 도구입니다. 편집 화면에서 저장한 것만으로 운영 사이트가 바뀌지는 않으며, 내보낸 파일을 이 폴더에 반영한 뒤 커밋·푸시해야 합니다.

문의 폼은 메일 앱을 여는 `mailto:` 방식입니다. 별도 서버 전송 기능은 없습니다.
